# XaeroFriends

**XaeroFriends** — это Fabric-мод для создания списков друзей и приватного обмена метками (вейпоинтами) в **Xaero Minimap** и **Xaero World Map**.

Основная фишка мода — **визуальное отображение чужих меток в реальном времени** прямо на ваших картах и игровом экране, а не просто отправка координат текстом в чат.

## 🌟 Особенности / Features

* **Live Waypoint Rendering:** Метки друзей динамически появляются на ваших картах и игровом экране в реальном времени, как ваши собственные.
* **Friend & Trust System:** Управляйте списком игроков и назначайте статус *"доверенного"* через удобное внутриигровое меню.
* **Flexible Privacy:** Вы сами выбираете, кто увидит вашу метку — никто, все друзья или только доверенные лица. *Метки смерти никогда не передаются автоматически.*
* **Server-Side Security:** Сервер строго контролирует настройки приватности и отправляет данные только тем игрокам, кому разрешено.

## ⚠️ Важно / Important

Для работы всех сетевых функций мод **обязательно должен быть установлен как на сервере, так и на клиентах игроков**. 
*(The mod must be installed on both the server and the clients of the players).*
